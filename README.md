# Sobre el proyecto

> Este proyecto es fruto del trabajo en equipo para presentar ante la XPOCET de la UAEH, en ICBI. Creado por alumnos del la Lic. Ciencias Computacionales del tercer semestre.

   ## Nombre del proyecto
  - Manos al Volante

   ## Descripción
  - Un par de guantes inalámbricos que convierten tus manos en el volante, la palanca de cambios, el acelerador y el freno de un simulador de manejo en Unity. Sensores de movimiento detectan cómo giras y cuándo cambias de velocidad, y motores de vibración te avisan de baches, franjas, choques y cambios metidos. Es un simulador educativo para practicar conceptos y secuencias antes de manejar, no un sustituto de clases reales.
  
   ## ¿Qué es?
  - Es un videojuego de simulación de conducción asistida por 'guantes electrónicos' que funcionan como un control inalámbrico, con la diferencia de que la experiencia es más intuitiva, llamativa, entretenida y diferente a comparación de los controles para videojuegos más comunes. 
    
   ## ¿Cómo funciona?
  - El proyecto combina 2 polos muy importantes de la tecnología, el software y el hardware. Utiliza electrónica digital para el control físico del sistema y software para su representación de esta misma.
  - El proyecto contiene la integración de Unity con librerías para poder funcionar con electrónica digital (Como sensores y microcontroladores).
  - Funcionará a base de los guantes electrónicos, usarán sensores de fuerza, Giroscopio, Acelerómetro, etc. Para mandar señales al ESP32 DevKit V1 (módulo ESP32-WROOM-32) para que le mande señales a Unity y este las lea.
